# LA Brow 0.2.0

The first signed release of the complete Android application together with the backend service and the web client it serves.

## What this release contains

| Component | Description |
| --- | --- |
| Android application | Browser client on GeckoView with a control center that drives browser scoped environment virtualisation |
| Backend service | Python service exposing the environment pipeline, profiles, diagnostics, DNS probes and the add-on compatibility layer |
| Web client | Single page control surface served by the same backend service |
| Add-on compatibility | Desktop Firefox theme rules and add-ons are inspected, scored and answered at install time |

## Android application

The application targets Android 8.0 and newer, uses the GeckoView engine and applies every environment control inside the browser only. The control center exposes six surfaces.

| Surface | Purpose |
| --- | --- |
| Browser | GeckoView session with the current virtual environment applied |
| Environment | Location, timezone, locale, privacy preset and the eleven pipeline stages |
| Add-ons | Desktop Firefox manifest inspection, compatibility scoring, install gate and theme activation |
| Network | Resolver selection, DNS over HTTPS and DNS over TLS probes, transport and VPN state |
| Profiles | Environment profiles with validation, save and removal |
| Settings | Server address, privacy preset, private browsing and diagnostics level |

The interface uses a dark gradient design with neon accents, and the active add-on theme drives the application accent gradient.

## Installation

1. Download the package that matches the device architecture, or the universal package when unsure.
2. Allow installation from the file manager or browser that opens the package. Android reports the package as coming from an unknown source because the project is not distributed through a store.
3. Start the backend service on a host reachable from the phone with `python3 -m api.server --host 0.0.0.0 --port 8000`.
4. Open the application settings and set the server base address to the backend host, for example `http://192.168.1.20:8000`. The default value `http://10.0.2.2:8000` addresses a backend running on the host of an Android emulator.

## Known limitations

- The desktop engine build and the update system are not executed in the build environment and are recorded as not applicable.
- Environment controls are browser scoped. They do not provide anonymity, do not change the public address observed by websites and never modify device or network DNS settings.
- Packages are debug signed in the continuous integration workflow and release signed in this release workflow with the project release key.
- The application is not published to any application store.
- Desktop Firefox extensions that depend on desktop only manifest sections are accepted with an explicit notice that parts of the add-on may not display or behave correctly on the mobile application.
