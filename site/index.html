LA BROW browser scoped environment virtualization
desktop control center, web client and android application

One deterministic environment pipeline, shared by every client.

Virtual location, timezone, locale, resolver and privacy policy are resolved once per navigation and reported per stage. Desktop Firefox themes are translated into the application gradient, desktop add-ons are scored against a reviewable matrix, and the install flow stops until the compatibility notice is confirmed.

location, timezone, locale, resolver, policy, diagnostics and add-on compatibility in a single interface contract

Environment Surfaces

Every surface is resolved, reported and bounded by explicit limitations.

location

Radius bounded virtual mode

Seeded and reproducible sampling inside the permitted radius. Physical provider fallback is blocked while virtual mode is active.

timezone

Browser scoped offset

JavaScript and formatting surfaces follow the profile zone. The operating system clock is never modified.

locale

Five distinct surfaces

Browser locale, language preference, HTTP preference, JavaScript surface and operating system locale stay separate values.

resolver

Browser scoped DNS

DNS over HTTPS and DNS over TLS profiles with explicit fallback confirmation. System resolver files are read and hashed only.

diagnostics

Consistency findings

Redaction levels, mismatch findings across surfaces and structured pipeline events for every resolution.

add-ons

Desktop theme translation

Theme colours become the application gradient. Unsupported surfaces are refused and reported, never silently accepted.

Interface Language

Dark first, gradient driven, built for status reading at a glance. A phone rendering of the same layout follows the design system that ships in the application.

Run It

python3 -m api.server --host 0.0.0.0 --port 8000 --repo .

The web control center is served at the root. The interface exposes environment resolution, profiles, resolver probes, diagnostics, recorded add-ons and themes. The Android application reads the same interface and assembles through the android-build workflow with the Android platform 35.

Statements

Environment controls do not guarantee anonymity and do not change the public address observed by websites. Resolver configuration never modifies device or network settings. While virtual location mode is active the browser never falls back to the device location provider.
